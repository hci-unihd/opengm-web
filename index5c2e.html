OpenGM

OpenGM is a C++ template library for discrete factor graph models and distributive operations on these models. OpenGM handles large models with no restrictions on the factor graph model and provides state-of-the-art optimization and inference algorithms.
After the release of the first vision in 2010, we focus on making OpenGM as flexible as possible such that it can work with the large scope of different models. To be also efficient in terms of runtime some solvers are specialized for subclasses. Furthermore within version 2 we start to provide wrappers for other projects/code and change to the MIT-licence.
